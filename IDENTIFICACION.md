# Consigna 1 · R1

Este repositorio reúne los cinco ejercicios: Hola mundo, tarjeta con props, contador, lista de tareas y formulario de saludo. Cada carpeta `Proyecto1` a `Proyecto5` se instala y ejecuta de forma independiente.

La copia de GitHub contiene únicamente el código activo. No incluye las carpetas históricas con fechas mencionadas en el README, dependencias ni compilaciones. No hay backend ni base SQL.
